Real recorded sounds, all CC0. Names match the game slots: shot0 shot1 shot2 en rl hit kill hurt step.
Files here replace the synthesized sounds. Delete a file to bring the synthesized version back for that slot.
shot0 = BR-12 rifle, shot1 = Wasp SMG and pistol, shot2 = Breaker Pump shotgun.

battle_ambience.ogg/.mp3  cinematic battle bed (drone, bombing, heavy fire). The game plays four copies at once
                          at different offsets/speeds/filters so every layer overlaps. Delete both files to
                          fall back to the old synthesized drone.
voices/*.ogg/.mp3         ally callouts (cover_me, watch_my_back, medic, look_out, call_backup, go_go_go).
                          Allies shout these during fights, overlapping freely.
